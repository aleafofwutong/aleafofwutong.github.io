配置

set print array on

设置数组打印格式

set print sevenbit-strings on

字符串正常显示

set print pretty on

结构体自动缩进、格式化（超级美观！）

set print array-indexes on

设置打印数组下标

set print elements 200

数组只打印前200个

set print elements 0

打印所有元素（不推荐，易刷屏）

  • 不常用

    set print array-indexes on # 显示数组下标 [0] [1]

    set print repeats 0 # 连续相同值合并显示（比如 0x00… 100 times）

    set print union on # 联合体也美化

    set print object on # 指针自动解引用显示真实类型

    set print static-members on # 显示静态成员

    set print vtbl on # 显示虚函数表

    set print demangle on # 自动还原C++函数名
