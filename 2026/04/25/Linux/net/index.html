netstat

显示网络连接、路由表、接口统计等信息的命令

列名 含义 详细解释
Proto 协议 告知该连接使用的是 TCP 还是 UDP 协议。TCP 是面向连接的（如网页浏览），UDP 是无连接的（如 DNS 查询）。
Recv-Q 接收队列 指已接收但尚未被本地程序取走的数据字节数。正常情况下应为 0。如果数值很高，说明程序处理速度跟不上网络接收速度。
Send-Q 发送队列 指本地已发送但远程主机尚未确认接收的数据字节数。通常也应为 0。数值持续较高可能意味着网络拥塞或远程主机响应慢。
Local Address 本地地址 本机监听的 IP 和端口号。例如 localhost:7897 表示程序正在监听本地回环地址的 7897 端口。
Foreign Address 远程地址 与本机通信的远程主机的 IP 和端口号。如果是 0.0.0.0:*，表示目前该端口正在等待连接，还没有明确的远程对象。
State 连接状态 描述当前的连接阶段。最常见的是 LISTEN（监听中）和 ESTABLISHED（已建立连接）。
列名 含义 详细解释
Proto 协议 固定为 unix，表示这是本地进程间通信协议。
RefCnt 引用计数 连接到此套接字的进程数量。例如 3 表示有 3 个进程正通过这个套接字进行交互。
Flags 标志 通常显示为 [ ] 或 ACC (SO_ACCEPTON)。ACC 表示该套接字正在等待连接请求。
Type 类型 常见的有：• 流 (STREAM)：类似 TCP，面向连接，可靠的数据流。• 数据报 (DGRAM)：类似 UDP，无连接，离散的数据包。
State 状态 • 已连接 (CONNECTED)：连接已建立。• 聆听 (LISTENING)：正在等待连接。• 空 (空白)：表示未连接。
I-Node 索引节点 该套接字在文件系统内核中的唯一标识号。
路径 (Path) 套接字路径,套接字文件的具体位置。很多系统服务使用物理文件（如 /run/…）作为通信入口。如果是空白，通常是匿名套接字。

ss

列名 含义 详细解释
Netid 网络协议 显示套接字使用的网络协议，如 u_str 表示 UNIX 域套接字。
State 连接状态 描述当前的连接阶段。常见状态包括 LISTEN（监听中）、ESTABLISHED（已建立连接）等。
Recv-Q 接收队列 指已接收但尚未被本地程序取走的数据字节数。正常情况下应为 0。如果数值很高，说明程序处理速度跟不上网络接收速度。
Send-Q 发送队列 指本地已发送但远程主机尚未确认接收的数据字节数。通常也应为 0。数值持续较高可能意味着网络拥塞或远程主机响应慢。
Local Address:Port 本地地址和端口 显示本机监听的 IP 和端口号。例如 *:101570 表示程序正在监听所有接口的 101570 端口。
Peer Address:Port 远程地址和端口 与本机通信的远程主机的 IP 和端口号。如果是 :，表示目前该端口正在等待连接，还没有明确的远程对象。

ifconfig

显示或配置网络接口的命令

列名 含义 详细解释
Link encap 链路封装 显示网络接口使用的链路层协议，如 Ethernet 表示以太网。
HWaddr 硬件地址 显示网络接口的物理MAC 地址，例如 00:0c:29:8e:9d:3b。
inet addr IPv4 地址 显示分配给该接口的 IPv4 地址，例如 192.168.1.101。
Bcast 广播地址 显示该接口的广播地址，例如 192.168.1.255。
Mask 子网掩码 显示该接口的子网掩码，例如 255.255.255.0。
UP 状态 显示该接口是否已启用。例如 UP 表示已启用。如果显示 DOWN，则表示未启用。
BROADCAST 广播能力 显示该接口是否支持广播功能。支持广播的接口会显示 BROADCAST。
RUNNING 运行状态 显示该接口是否正在运行。例如 RUNNING 表示接口已经连接并正常工作。
MULTICAST 多播能力 显示该接口是否支持多播功能。支持多播的接口会显示 MULTICAST。
MTU 最大传输单元 显示该接口的最大传输单元（MTU），即一次可以发送的最大数据包大小，例如 1500 字节。
Metric 路由度量 显示该接口的路由度量值，通常用于路由选择算法中。较低的值表示更优的路由。
RX packets 接收数据包数 显示该接口接收的数据包总数，例如 3277。
RX errors 接收错误数 显示该接口接收过程中发生的错误数量，例如 0。
RX dropped 接收丢弃数 显示该接口接收过程中丢弃的数据包数量，例如 0。
RX overruns 接收溢出数 显示该接口接收过程中发生的溢出数量，例如 0。
RX frame 接收帧错误数 显示该接口接收过程中发生的帧错误数量，例如 0。
TX packets 发送数据包数 显示该接口发送的数据包总数，例如 247。
TX errors 发送错误数 显示该接口发送过程中发生的错误数量，例如 0。
TX dropped 发送丢弃数 显示该接口发送过程中丢弃的数据包数量，例如 0。
TX overruns 发送溢出数 显示该接口发送过程中发生的溢出数量，例如 0。
TX carrier 发送载波错误数 显示该接口发送过程中发生的载波错误数量，例如 0。
collisions 碰撞数 显示该接口发送过程中发生的碰撞数量，例如 0。
txqueuelen 发送队列长度 显示该接口的发送队列长度，例如 1000。
RX bytes 接收字节数 显示该接口接收的总字节数，例如 317871 字节。
TX bytes 发送字节数 显示该接口发送的总字节数，例如 32274 字节。
