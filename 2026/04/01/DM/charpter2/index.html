2.1 命题合式公式语义

命题逻辑公式的真值

P∧Q的真值

  • def 2.1.1

    • 指派函数，简称指派，是一种从合式公式到集合{0,1}的函数，记作σ
    • σ:Q→ {0,1}

  • def 2.1.2

    • Q是命题变元，则Q的语义是指Q的真值。即σ(Q)=Q^{σ},其中Q^σ∈{0,1}

  • def 2.1.3

    • Q,R是命题变元，σ 是指派，合式公式联结词的语义指定为对应的逻辑运算
      • .e.g (¬ Q)是合式公式，σ (¬ Q)=¬σ(Q)

  • def 2.1.4

    • 若Q，R是合式公式，σ(Q⊨R)=σ(Q)⊨σ®

  • def 2.1.5

    • 若Q，R是合式公式，σ(Q⇔R)=σ(Q)⇔σ®

  • def 2.1.6

    • 如果真值指派σ使得σ(Q)=1,则称σ满足Q
    • 如果每个真值指派都满足Q，那么Q是有效式，永真式，重言式。
    • 如果每个真值指派都不满足Q，那么Q是矛盾式，永假式，不可满足式。
    • 如果至少有1个真值指派都满足Q，那么Q是可满足式。

2.2推论式与等价式的语义

  • def 2.2.1

    • 设Q和R都是合式公式,Q⊨R是推论式，若对于任意指派函数σ,σ(Q)⊨σ® 皆为真，则称Q语义推出R

  • def 2.2.2

    • 设Γ是合式公式合集，R是合式公式，Γ⊨R是推论式，若对于任意指派函数σ,σ(Γ)⊨σ®

  • def 2.2.3

    • 设Q_{1},Q_{2},Q_{3},⋯,Q_{n}是命题公式，Γ={Q_{1},Q_{2},⋯ Q_{n}},若对于任意指派函数σ,如果σ(Q_1),σ(Q_2),⋯,σ(Q_n)皆为真，则Γ®为真，则称Q_{1},Q_{2},Q_{3},⋯ ,Q_{n}语义推出R,记为Q_{1},Q_{2},Q_{3},⋯ ,Q_{n}⊨ R(也是推论式)。若R为空集，记作⊨ R。
